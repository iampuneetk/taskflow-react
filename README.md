# TaskFlow

TaskFlow is an advanced task-management application built with React.

## Features

- Add, edit and delete tasks
- Mark tasks as completed
- Task descriptions
- Categories
- Priority levels
- Due dates
- Search
- Status, category and priority filters
- Multiple sorting options
- Task statistics
- Overdue-task detection
- Dark mode
- Keyboard shortcuts
- Local Storage persistence
- Responsive design

## React concepts used

- Components
- Props
- useState
- useEffect
- useRef
- Lists and keys
- Controlled inputs
- Conditional rendering
- Derived data
- Custom hooks
- Context API
- Local Storage
- Event handling

## Keyboard shortcuts

| Shortcut | Action |
|---|---|
| N | Focus task-title input |
| / | Focus search |
| D | Toggle theme |
| Escape | Cancel editing |
| Ctrl + Enter | Submit task form |
